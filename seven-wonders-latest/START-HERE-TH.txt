คู่มือเริ่มต้น
==============
ไฟล์นี้เป็นเว็บเวอร์ชันล่าสุด รวม 19 หน้า รูป 28 ภาพ เกมจิ๊กซอว์ และหน้าทายภาพก่อนแต่ละสถานที่

1. แตกไฟล์ ZIP ก่อนใช้งาน
2. ติดตั้ง Node.js หากเครื่องยังไม่มี
3. เปิด Terminal หรือ Command Prompt ในโฟลเดอร์ที่แตกไฟล์
4. พิมพ์: node serve.mjs
5. เปิดเบราว์เซอร์ไปที่ http://127.0.0.1:4173

ไม่ต้องติดตั้งแพ็กเกจเพื่อเปิดเว็บที่ build ไว้แล้ว
หากต้องการแก้โค้ด ใช้ npm install และ npm run dev
อย่าเปิด dist/index.html ด้วยการดับเบิลคลิก ให้ใช้คำสั่งด้านบน
